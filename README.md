# UB Beauty Salon — Chatbot (суурь бүтэц)

Facebook Messenger дээр ажилладаг гоо сайхны салоны чатбот. **2 тусдаа AI**-тай:

1. **Үйлчлүүлэгчийн AI** — Facebook-ийн контент (пост/зар)-оос орж ирсэн хэрэглэгчтэй харилцана. Аль үйлчилгээнээс ирснийг ялгаж, тухайн үйлчилгээг онцолсон мэндчилгээ өгч, цаг захиалга авна.
2. **Admin AI** — ажилчидтай (Telegram/Messenger) харилцаж, мэдээллийн санг хөгжүүлэх (үнэ/тайлбар нэмэх) болон гараар ирсэн цаг захиалгыг бүртгэнэ.

> Технологи: **Node.js + Express**, **Vercel** (serverless) дээр ажиллана. AI тархи: **Anthropic Claude** (`@anthropic-ai/sdk`).

---

## Боломжууд (энэ үе шатанд бэлэн)

- ✅ Контентоос хамаарсан ухаалаг мэндчилгээ (FB `ref`/postback → үйлчилгээ таних)
- ✅ 5 үйлчилгээний мэдээллийн сан (нэмэлт сонголт, хэсгийн үнэ зэргийг дэмжсэн бүтэц)
- ✅ Цаг захиалга — утас + үйлчилгээ + огноо/цаг тодруулж, **гүйлгээний утга = `цаг, өдөр, утас`**
- ✅ Цаг цуцлах бодлого — **4+ цагийн өмнө** мэдэгдвэл урьдчилгаа буцаана
- ✅ Цаг сануулагч — Vercel Cron-оор захиалгатай цагаас өмнө (**default 2 цаг**) сануулна
- ✅ Admin AI — үйлчилгээ засах/нэмэх (нэр, үнэ, **зураг**, үргэлжлэх хугацаа), гараар захиалга бүртгэх, **артист бүртгэх/удирдах**
- ✅ **Зураг байршуулах** — админ Telegram-аар зураг илгээхэд автоматаар Cloudinary-д **жижигрүүлж** байршуулаад, үйлчилгээний зурагт хэрэглэнэ
- ✅ **Артистын амралт** — 1–3 хоног шууд, **3-аас дээш хоног** бол үндсэн админы зөвшөөрөл шаардана
- ✅ **Хуваарийн Google Sheet** — артистуудын 7 хоногийн ажиллах цаг, амралт, үйлчилгээг Google Sheet-д автоматаар, ойлгомжтой хүснэгтээр гаргана
- ✅ **Артист AI** — артист бүр Messenger-ээр (тусдаа хуудас) ажиллах цагийн хуваараа тохируулж, амралтаа зааж, өөрийн захиалгаа харна
- ✅ **Артистаар захиалга хуваарилах** — үйлчилгээг хийдэг, тэр цагт сул артистуудаас **хамгийн бага ачаалалтайг** нь автоматаар сонгож ачааллыг тэнцвэржүүлнэ. Захиалга орох бүрт оноогдсон артист руу Messenger-ээр мэдэгдэнэ
- 🔧 Төлбөр — одоогоор **stub** (гар шилжүүлгийн заавар). QPay зэргийг дараа залгахад бэлэн

> **Артистын хуваарь (v1):** нэг үйлчилгээ = **1 цаг**, нэг артист нэг цагт нэг хүн.
> Дараагийн хувилбарт үйлчилгээ тус бүрийн үргэлжлэх хугацааг нарийвчилна.

## ⚠️ Чухал: Vercel + мэдээллийн сан

Vercel бол serverless — **файлын систем түр зуурынх**. Одоогийн `jsonStore` нь in-memory тул
process дахин эхлэх бүрт өгөгдөл устана. **Production-д заавал hosted DB** (Neon / Supabase /
Vercel Postgres) руу шилжүүлнэ. Үүний тулд `src/db/jsonStore.js`-тэй ижил интерфейстэй
`createPostgresStore()` бичээд `src/db/repository.js` доторх нэг мөрийг солиход хангалттай.
Бусад код өөрчлөгдөхгүй.

Мөн ярианы түүх (conversation history) одоогоор in-memory Map-д хадгалагдаж байгаа тул үүнийг
ч DB рүү зөөх шаардлагатай (код дотор `TODO` гэж тэмдэглэсэн).

## Vercel дээр deploy хийх

1. Git repo-той холбоод Vercel дээр import хийнэ.
2. **Environment Variables** дотор `.env.example`-ийн утгуудыг оруулна.
3. Facebook App → Messenger → Webhook URL: `https://<domain>/webhook`, Verify Token: `FB_VERIFY_TOKEN`.
4. **Артистын хуудас** (тусдаа FB Page) → Webhook URL: `https://<domain>/webhook-artist`, Verify Token: `ARTIST_FB_VERIFY_TOKEN`. Page Access Token-ийг `ARTIST_PAGE_ACCESS_TOKEN`-д оруулна.
5. Telegram bot webhook: `https://<domain>/admin/telegram` (setWebhook).
6. Cron нь `vercel.json`-д тохируулагдсан (`/cron/reminders`, 15 минут тутам).

## Үйлчилгээ таних (FB контент → мэндчилгээ)

Facebook пост/зарын **m.me** холбоос эсвэл ad referral дээр `ref` утга дамжуулна. Жишээ:

```
m.me/<page-username>?ref=green-peel
```

`src/data/services.js` доторх `refKeys` жагсаалтаар `ref`-ийг үйлчилгээтэй тааруулна.
Таарвал тухайн үйлчилгээг онцолсон мэндчилгээ, таараагүй бол ерөнхий мэндчилгээ өгнө.

## Артист (хуваарь + автомат хуваарилалт)

**Зорилго:** артист бүр өөрийн ажиллах цагаа Messenger-ээр оруулж, үйлчлүүлэгч захиалахад
систем тухайн үйлчилгээг хийдэг, сул, **хамгийн бага ачаалалтай** артистад автоматаар оноодог болгох.

### Role (эрх)

- **manager** — бүх артистыг хянах (`day_overview` — хэн их/бага ачаалалтай), шинэ урилга (код)
  үүсгэх, артистыг идэвхгүй болгох эрхтэй. Өөрөө артист хийвэл хуваараа ч тохируулж болно.
- **artist** — зөвхөн ӨӨРИЙН хуваарь, амралт, захиалгатай ажиллана.

### Бүртгэл — нэг удаагийн баталгаажуулах код

1. **Урилга үүсгэх.** Менежер (артистын хуудсан дээрээс) эсвэл Admin AI (Telegram) шинэ хүний нэр,
   role (`artist`/`manager`), хийдэг үйлчилгээг өгнө → систем **6 оронтой нэг удаагийн код** буцаана.
2. **Код оруулах.** Тухайн хүн артистын FB хуудас руу кодоо илгээхэд **psid нь бүртгэлд холбогдоно**
   (код нэг удаа л ажиллана, дараа нь цуцлагдана).
3. **Хуваараа тохируулна.** Бүртгэгдсэний дараа ботод *"Да–Ба 10–18 ажиллана"* гэх мэт бичихэд
   долоо хоногийн хуваарь хадгалагдана. *"Маргааш амарна"* → тухайн өдрийг хаана.
4. **Захиалга.** Үйлчлүүлэгч тухайн үйлчилгээ захиалахад систем сул артистуудаас хамгийн бага
   ачаалалтайг нь сонгож, оноогдсон артист руу Messenger-ээр мэдэгдэнэ.

> **Эхний менежер** — Admin AI (Telegram) дээр `create_artist` role=manager-аар код үүсгээд, тэр
> кодыг менежерт өгнө. Менежер кодоо артистын хуудас руу илгээж бүртгүүлнэ. Цаашид менежер өөрөө
> бусад артистын код үүсгэнэ.

**Чухал зарчим — зөөлөн шилжилт:** Тухайн үйлчилгээнд артист бүртгэгдээгүй бол систем хуучин
«салон = нэг суудал» логикоор (нэг цагт нэг захиалга) ажиллана. Артист нэмэгдмэгц тэр үйлчилгээ
автоматаар артистаар тооцогддог болно.

**v1 хязгаарлалт:** нэг үйлчилгээ = 1 цаг; нэг артист нэг цагт нэг хүн. Үйлчилгээ тус бүрийн
үргэлжлэх хугацааг дараагийн хувилбарт нарийвчилна.
